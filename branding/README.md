# 游戏图标

- `game_icon.png`：游戏专用方形图标，内置 image_gen（imagegen 技能）生成的原创插画，可用于微信小游戏账号头像。
- `game_icon_512.png`：512×512 压缩上传副本，优先用于后台头像设置；原图保留。
- 运行时精简副本：`assets/game_art/game_icon.jpg`（256×256），用于游戏内等级卡。
- 不替换 Creator 构建产物中的引擎标识；账号头像需在微信后台由用户设置。
