# 1.2 可持续约会、六章故事与重玩

日期：2026-11-13。正式客户端仍为 Cocos Creator 3.8.8 微信小游戏，版本号为 1.2.0，存档版本保持 **v3**。本轮为本地候选包，已实际构建，未提交、未推送、未上传；本轮新增功能尚未真机复测。

## 本轮增加的内容

### 1. 订单节奏

- 生成订单时同时避开当前其余订单和最近三单；归一签名会先把同一 `itemId` 的重复行累加，再排序，因此“`coffee_02 x1 + coffee_02 x1`”与“`coffee_02 x2`”以及模板 ID 不同的同需求订单都会被视为重复。
- 可选模板不足时按“避开当前订单和最近三单 → 只避开当前订单 → 允许重复”三档退化，不循环重试，也不会在有候选时留下空槽。
- 保留教程首单和开局的三种不同需求：教程咖啡、咖啡双份、浓缩咖啡；本轮重点减少后续替换订单的重复。
- `orders.json` 增加低成本咖啡/花/甜点/礼物组合；`order_latte_date` 延至 Lv5，实际 Lv1/Lv2 单咖啡链可选池的总基础成本不超过 8。
- 单测覆盖重复抑制、不同 ID 同需求、拆分需求行归一、最近三单、可选不足回退、教程保留、实际可选池成本和锁定链过滤。

### 2. 独立谜题重玩

- 已领取的章节可以从目录或完成页点击“重玩谜题”，不准备剧情订单、不消耗体力。
- 重玩使用 `play.replays[chapterId]` 独立进度；原章的 `claimed`、步骤、线索、提示次数、纪念物、回忆解锁和一次性奖励都不被改写。
- 练习可以退出后恢复；`startReplay` 在练习进行中会恢复，练习完成后再进入会开新一轮；“再练一次”会显式重置练习。
- 练习完成页明确显示“练习完成，无重复奖励”，不出现原章领取按钮。
- 存档 v3 新增可缺省字段 `replays`，旧 v3 存档读取时为空对象；不需要提升存档版本。
- 单测覆盖未领取不能重玩、跳过/成功重玩、重玩反复领取无奖励、旧 v3 缺字段和重启恢复。

### 3. 可重复小约会

- `small_dates.json` 提供四组原创主题：晨间咖啡、窗边下午茶、散步带花、电影小夜晚。
- 当前订单、轮换计数和完成次数保存在 `play.smallDate`，切页/重启不会随意换目标。
- 交付 token 绑定 `currentId + rotation`；缺失或过期 token 返回 `STALE_DATE`，不扣物品、不发奖、不轮换。奖励事件中同步重入由私有 `deliveringSmallDate` 保护拦截。
- 只从玩家已解锁链和等级中筛选，单项物品等级不超过 3，常规总基础物品成本 2–8。
- 交付前用棋盘原子物品需求一次性检查；失败不扣物品。成功后才发小额金币/爱心/经验，并轮换到下一个可用主题。
- 可选项多于一个时，轮换会避开刚完成的主题；确定性由 rotation 决定，重启后仍保持。
- 绝不奖励体力或剪刀；成功交付记入既有 `orders` 统计，因此兼容现有心愿进度。
- 小约会页面展示主题、完成次数和具体金币/爱心/经验奖励；产品文案改为“备好心意，就出发吧 · 完成后还有下一场约会”，不强调内部扣物/奖励实现。
- 没有真实每日限时、签到或强制等待；小约会使用现有 JSON 配置结构，不伪造 Cocos 资源 meta。

### 4. 六章故事解谜

| --- | --- | --- | --- |

| `love_letters` | 100 天，100 封情书 | Lv3 | 排列信件 |
| `namsan` | 南山塔，向你求婚 | Lv5 | 连线点灯 |
| `hengdian_newyear` | 横店跨年，再一起回温州 | Lv6 | 按回忆册页码排列照片，不代表实际游览时序 |

| `leqing_wedding` | 乐清草坪婚礼 | Lv10 | 草坪灯串连线 |

- 新章均使用 `memories.json` 已有原创配图与真实故事日期：横店从 2023-12-30 起，丽江拍摄于 2026-05-22，乐清草坪婚礼为 2026-10-03。
- 每章两份剧情订单，需求链在对应解锁等级已经开放；乐清章不把领证或答谢宴混作婚礼。
- 三章解谜分别使用排列、找物密码和连线，线索独立；横店序列明确写成“回忆册这一页的排版顺序/页码”，不冒充用户未确认的旅行时间线；连线底部提示按 start/end 计算，婚礼“左上连入、右下连出”独立成立。
- 新纪念物位置与旧物不重叠：客厅 `(0, 26)`、卧室 `(160, -6)`、花园 `(0, -6)`。丽江图标继续使用 `flower_06`，纪念名改为“丽江旅拍花束”避免图文错配。
- 家园纪念架按当前房间数量等距排布，标题宽度取 `min(244, 间距-12)`，支持两行/SHRINK；图标与标题共用足够触摸区域，不覆盖家具操作栏。
- 配置校验新增：章节需求链必须在该章等级已解锁、纪念物坐标不得完全重叠、每章两步、解谜可解且连线初始状态不能已经通关；小约会必须有 4 组以上、成本 2–8、物品等级不超过 3、至少一组 Lv1 可玩。

### 5. Cocos UI

- 今日约会目录按每页 3 章分页，六章共两页，不再沿用会溢出的 `index * 218` 固定排版。
- 小约会入口固定在目录可见区域，显示当前主题、完成次数和赴约入口。
- 已完成章显示“重玩谜题”和“查看纪念”两个独立按钮；完成页同样区分领取、重玩和查看纪念。
- 重玩页清楚标注“重玩练习 · 不消耗体力 · 不重复发奖”，练习完成显示无重复奖励。
- 缺物品时按钮直接显示缺少的物品名，并可回合成页准备；跳过谜题继续保留二次确认。
