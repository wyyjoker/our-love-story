## 当前行为

- 三个固定订单槽：大幅原创顾客半身像为主体，所需物品排列在人物旁；备齐时显示居中珊瑚粉交付按钮。保留物品送达、顾客致谢、奖励飞入和升级排队反馈。
- 没有免费换单、钻石换单或二级换单菜单。交付完成后自动补新订单；旧版换单入口的兼容接口返回 `DISABLED`，不改订单、不扣钻石。旧存档中的刷新时间字段保留为无效历史数据，钻石获取途径文案也不再提换单。
- 四枚独立插画导航，保持页面选中状态；三尺寸订单区为人物与需求物品留足独立空间。
- 背包六格：将物品拖到棋盘工具栏的背包图标即可收纳，悬停高亮，松手后容量更新；拖入不打开其他页面。点背包再点击存放物品取回。满背包时不丢物品。
- 剪刀是棋盘上的实际物品，可移动、收纳、合成；拖到二级以上物品可拆成两个低一级物品。已取消正式界面的直接拆分按钮。

| 剪刀等级 | 满耐久可用次数 |
| --- | --- |
| 1 | 1 |
| 2 | 3 |
| 3 | 8 |
| 4 | 20 |
| 5 | 50 |

两把同级剪刀合成时，按剩余次数占总次数的比例折算新剪刀次数，向下取整，最低为一次。例如两把各剩一次的二级剪刀合成三级后为两次，不会补满为八次。最高五级；不能把剪刀拆成更多剪刀。

最后一次使用会消耗剪刀并把腾出的格子用于第二个拆分物品，因此满棋盘也能完成；还有多次可用的剪刀需另外留一个开放空格。拆分不消耗体力。

## 存档与获取

- 物品实例增加 `remainingUses`，棋盘、背包及恢复箱保存原 UID 和剩余次数。v8 迁移保留旧资产、进度和有限剪刀库存。
- 旧库存保留为“待取剪刀”，在背包点击取出一把一级剪刀后库存减一；棋盘满时不扣库存。没有把库存自动铺到新手九格里，也没有重复赠送。
- 原有探索剪刀奖励保留；第七天签到额外给一把二级剪刀，进入恢复箱，原有签到货币奖励不变。
- 玩法仍由纯 TS 规则和 `GameContext` 操作；UI 负责显示、拖动与反馈。奖励到账动画不修改经济状态。
