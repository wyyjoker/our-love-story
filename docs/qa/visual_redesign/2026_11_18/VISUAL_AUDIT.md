# 29 张方案图逐页对照

对照 2026-11-17 的原始方案图与 Creator Web Mobile 截图。画面中的等级、资源、解锁数和奖励来自截图测试档。取证范围分开记录在各次 `result.json` 中，包含构建摘要。

| 页 | 实际画面与设计核对 |
| --- | --- |
| 01 封面 | 原先沿用室内背景。现用花园小屋与茶桌插画，标题、日期、进入按钮由游戏绘制。核对了新封面图和当前游戏截图。 |
| 02 合成 | 三个半身顾客、需求托盘、可交付按钮和奶油色木框棋盘对应方案，底部保留背包、说明和家园。 |
| 03 生成器摆放 | Lv12 演示档可见多台机器与普通物品占同一棋盘，开放格内仍留有空位。演示档保留了高等级锁格。 |
| 04 家园 | 房间栏位于状态栏下方。家具和壁画随真实摆放进度显示，截图不预置方案中的家具数量。 |
| 05 家园编辑 | 选框、名称、对齐线、比例和操作按钮可见，撤销与确定通过触摸检查。 |
| 06 家具目录 | 场景保留在上方，底部纸质目录显示四款家具、实价、筛选与翻页。 |
| 07 回忆相册 | 保留插画卡片、纸框、已珍藏数量和四个入口。当前包含 42 条回忆，分页按实际条数生成。 |
| 08 心动日记 | 大图、日期、正文及上一页和下一页分开，长正文可滚动。 |
| 09 时间轴 | 已珍藏项显示日期和预览，未解锁项仅见锁和解锁提示。 |
| 10 本机照片 | 相册支持本机图片的分页与点开预览；截图使用测试用本机图片，微信照片权限和路径仍需真机验证。 |
| 11 今日日记 | 显示文字输入、照片位及保存操作。空档显示照片占位，内容与照片需要玩家填写。 |
| 12 心愿任务 | 纸卡显示进度、奖励和领取状态，完整心愿列表可翻页。每日任务位于补给页独立分页。 |
| 13 七日签到 | 七日奖励及领取操作同屏，奖励图标和数量取真实配置。 |
| 14 背包 | 皮质边框内显示 6×6 格。已用容量、上限、取回和钻石扩容均可从本页辨认。收纳的机器显示原图和等级，取回后继续使用同一实例。 |
| 15 补给 | 补给兑换和满盘奖励分区显示，正确区分满体力、空奖励箱和可领取状态。 |
| 16 物品详情 | 道具显示实际等级和说明，打开宝箱、使用补给和查看图鉴各用独立操作。普通合成物新增每件售价和出售确认，可能影响订单时显式提示。 |
| 17 收集图鉴 | 独立纸质图鉴册，四列物品卡、合成链分页、收集进度与永久体力奖励。已发现物品可点开详情，未发现格只显示统一问号。 |
| 18 生成器详情 | 机器图、等级、次数、恢复进度及产出概率均来自选中的棋盘实例。强化和恢复操作按状态出现。 |
| 19 生成器合成 | 拖动同种同级机器后生成更高级实体并保留在目标格。实际画面显示升级后的等级标。 |
| 20 回忆探索 | 六章分两项一页展示，标题卡、小约会与推荐操作清楚。章节锁定和完成状态随存档变化。 |
| 21 搜索谜题 | 场景、标记、线索、密码格和确认操作同屏，错误和提示不扣体力。 |
| 22 信件排序 | 加入信封折痕、蜡印及四个顺序格。已选信件带序号，点回原信可重排。 |
| 23 灯串通路 | 入口和爱心出口对齐行列。顶部场景显示夜空和远处塔影，未通电的棕灰线路与亮起的金色线路可区分。已核对更新后截图。 |
| 24 设置 | 声音和触感独立，预览按钮按各自设置工作。微信音效和触感待手机核对。 |
| 25 订单备齐 | 居中纸卡展示准备好的物品、交付和关闭，初次拖动引导优先。 |
| 26 升级 | 画面显示新等级、解锁生成器和实际奖励，须点领取。 |
| 27 宝箱奖励 | 点击道具先查看，确认后奖品飞入格内或恢复箱。角落宝箱的动画会向棋盘内展开，活动期间首次引导和交付提示让出画面；已捕捉四级箱的动画中段。 |
| 28 订单备货 | 显示订单需求差额、棋盘已有数量、来源及可横滑的合成路径。未发现路径节点为问号。 |
| 29 小屋商店 | 新增体力补给和背包扩容入口，按钮进入各自页面。生成器购买与待领条保留在商店下半部分，生效时直接进棋盘。 |

29 个页面和状态均已纳入对照，具体比例与构图随屏幕和存档变化。部分弹窗使用更紧凑的游戏内容排版。实际触摸回归、两次手机验收和连续游玩记录见 [实施记录](../../../VISUAL_IMPLEMENTATION.md)。
