# 界面布局整理（2026-11-16）

本轮为 1.3.0 本地候选，存档仍为 v8；承接 [人物订单与工具精修](CUSTOMER_TOOLS.md)，只调整表现与交互布局，不调整等级、产出、奖励或家具存档坐标。未提交、上传或新增手机验收。

## 实际调整

1. **合成页**：两排工具栏合并成一行约会目标，显示当前主题和备齐进度；橘树入口仍可见，包形拖放目标与补给入口固定在右侧。短屏压缩订单与底栏占用，空间优先给棋盘，六列继续铺满宽度、七行全部可见，不改渐进解锁规则。
2. **顾客订单**：保留人物与身旁物品，放大图标和数量标识，三卡交付按钮统一基线；短屏双需求采用并排排版，避免两件物品被纵向压小。继续保留准确到账、顾客致谢和顺序升级反馈，没有换单入口。
3. **状态与导航**：顶部铺稳定奶油色底，调整资源数字和签到、设置的间距；底栏图标固定尺寸，选中状态使用小底片，不再通过图标忽大忽小表现。所有入口继续遵循安全区。
4. **背包**：改为底部抽屉，显示六格储物、占用、点击取回和有限剪刀领取；删除重复的棋盘物品列表和分页。收纳通过棋盘拖入完成，抽屉打开时阻挡后方棋盘操作。剪刀耐久与合成规则保持原样。
5. **家园**：心愿缩为可点击的小卡，房间选择上移；装修进度和操作按钮统一到底部底座，进入编辑才显示缩放、旋转等控件；家具目录从底部打开。原有场景、家具位置与保存方式不变。
6. **回忆与补给**：相册合并重复标题，短屏扩大单张插画，时间轴增加可视区域；未解锁页面显示通用封签，继续隐藏个人故事和原插画。补给快捷入口降低视觉分量，满体力时显示“体力已满”，兑换禁用且不显示补充 0 点。

本轮复用已有原创插画与字体，没有新增美术文件或修改核心玩法。
