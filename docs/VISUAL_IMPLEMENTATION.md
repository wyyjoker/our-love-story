# 奶油水彩改版：实现与验证记录

更新：2026-11-18。完整目标仍为 `VISUAL_REDESIGN_PLAN.md` 的29张页面和关键状态，不把阶段通过视作整体完成。

## 已落地的玩法与界面

- 主棋盘7列×9行，共63格；新档9格开放，Lv12/15/18继续开放至49/56/63格。
- v9存档记录棋盘行列，旧42/48/63/81格按坐标迁移；超出新宽度的普通物品进入补发奖励，已有占格和解锁权保留。
- **生成器在主棋盘格内生产与合成**。可以拖入普通背包，每台占一格，取回保留同一台机器的等级、剩余次数和强化；冷却按实际时间恢复。奖励与购买直接进入主棋盘。
- **单件出售**。普通合成物的详情显示配置售价，确认时会提醒是否影响已备齐订单；出售后发金币并腾出该格。
- 点击格内生成器产出，长按松开查看详情，拖动移动或同类同级合成；详情显示等级、额度、冷却、普通/强化产出概率和2倍体力开关。
- 逐台保存UID、等级、剩余次数、恢复时间、强化偏好和位置；普通生成器60次，橘树10次、基础一分钟恢复一次。移动不补次数，合成按两台剩余额度比例保守折算，恢复进度取较保守的一方。
- 旧生成器数量转换为实体，只将旧共享剩余额度分配一次；超出棋盘容量的部分保留未领取的迁移奖励。该奖励只能领取到空格，没有存入入口。
- 商店购买、心愿、升级和章节奖励的实体生成器都放进棋盘空格。棋盘满时购买不扣费，奖励保持未领取，可以腾出空格再领。
- 合成页左上显示头像、等级、经验和爱心；体力、金币、钻石横排，右上可进入商店。底部左侧为背包，中间显示物品或约会目标，右侧回家园；任务和回忆从家园进入。
- 背包6格起步，逐格花钻石扩至6×6共36格。配置费用为首格10钻、每次递增2钻，领取前显示确切费用并确认；余额不足/上限/重复点击/旧档容量均有保护。
- 三位原创顾客站在需求托盘后，托盘显示物品和数量；备齐后显示豆绿色交付按钮。棋盘需求物品使用浅豆绿底和绿勾，交付时显示奖励到账反馈。
- 统一封面、背包、任务、日记、设置、道具详情和解谜等界面的纸张与按钮材质。签到页在同屏展示七日奖励和领取按钮；家园家具目录移到场景下方，壁画使用六张独立画作。
- 封面和启动画面采用新的花园小屋插画。信件排序使用蜡印和顺序槽，灯串显示通电底色与不同线路颜色。商店提供现有补给、扩容入口，购买和扩容仍由原操作处理。
- 网页调试版也从棋盘格点击生成器生产，拖动仍由和正式版相同的规则处理。
