# 1.1 今日约会与回忆解谜

日期：2026-11-12。正式客户端仍为 Cocos Creator 3.8.8 微信小游戏，版本 1.1.0。本轮为本地候选包，未上传微信后台。原 28 章、三个普通订单、家具、照片和存档权益保留。

## 如何游玩

合成页棋盘上方点击“今日约会”，选择一章。准备并交付两步指定物品，进入探索，完成后点击“领取回忆与纪念物”。准备订单不会过期，使用棋盘上的物品；已收纳物品需要先取回。

| 约会 | 开启条件 | 玩法 | 一次性奖励 | 家园纪念物 |
| --- | --- | --- | --- | --- |
| 舟山 · 相遇的线索 | Lv1 | 找齐三个标记中的线索，输入月份与日期组成的四位密码 | 金币120、爱心50、体力20、剪刀1 | 客厅：初识的心意礼盒 |
| 情书 · 把心意排成一句话 | Lv3，领取前章纪念 | 阅读四封信的便签，依次排列告白；点选过的信可撤回后续 | 金币180、爱心80、体力25、剪刀2 | 卧室：珍藏的情书 |
| 南山塔 · 点亮心意 | Lv5，领取前章纪念 | 点格子旋转线路，互相对接后由左上入口连到右下爱心 | 金币240、爱心120、体力30、剪刀2 | 客厅：南山塔的心意吊坠 |

体力奖励补至体力上限。每章奖励还会赠送对应回忆权益，已拥有的不重复扣费。家园对应房间增加“回忆纪念架”，展示已领取的纪念物；不计入原家具装修50点，点击可重读对应日记。

探索不扣体力，错误不会丢物品。提供三级免费提示和“跳过谜题”的确认/取消操作；跳过后仍可领取回忆。完成后可重读回忆及纪念物，奖励不重复发放。谜题里的邀请卡、便签和机关是为回忆册设计的游戏内容，不作为新增真实经历写进日记。

## 仓库与剪刀

- 点击合成页“仓库与剪刀”，或轻点棋盘物品，定位该物品所在列表页。
- 六个收纳位，点击“收纳”移入，点击仓库物品取回棋盘第一个空格；物品 UID 保留。普通订单与剧情订单均只使用棋盘上的物品。
- 新增系统初始赠送两把剪刀；每次拆分消耗一把，将二级以上物品拆为两个低一级同链物品，需要一格空位。不会增加物品的合成价值，也不增加合成统计。
- 仓库已满、棋盘已满、一级物品、无剪刀等失败均有反馈，不消耗物品或剪刀。

## 数据与实现

- `assets/resources/config/adventures.json`：剧情订单、线索、谜题初始状态/可验证解法、奖励和纪念物配置。纪念物坐标相对于所在房间的回忆纪念架。
- `game.json.toolbox`：仓库容量与初始剪刀；当前 UI 支持 1–6 个位置。
- `core/play/types.ts`：纯 TS 类型和线路连通判定；`gameplay/PlayService.ts`：仓库、拆分、订单和探索服务。
- UI 通过 `GameContext.playAction / puzzleAction` 操作，以 `PLAY_CHANGED` 和已有事件刷新；不修改 SaveData，不在 Cocos 里复制谜题判定。
- 存档 v3 增加 `play`：仓库、剪刀、各章订单阶段、线索、密码、信件选择、线路旋转、提示次数、完成方式和领奖状态。升级旧档前保留 `saveKey:backup` 原始数据，备份失败时阻止覆盖；原玩家资产和权益保持。
- 新配置使用稳定章节 ID；`claimed` 先记录再发奖，普通/跳过路线共用一次性领奖保护。存储失败由原有可见重试流程保留待写入的完整快照。
