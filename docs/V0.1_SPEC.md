# V0.1 规格摘要

## 闭环

启动 → 读档 → Merge 棋盘 → 点生成器 → 扣体力 → 生成物品 → 拖动合成 → 满足订单 → 交付 → 金币+XP+爱心 → 升级 → 解锁 → 自动保存 → 重进恢复。

## 棋盘

- 7 列 × 9 行 = 63 cells
- row-major：`index = row * columns + column`
- 工具：`indexToPosition` / `positionToIndex` / `isValidPosition`

## 拖动结果

| 目标 | 结果 |
| --- | --- |
| 空 | MOVE |
| 相同 definitionId 且未满级 | MERGE |
| 其他物品 | SWAP |
| 棋盘外 | CANCEL |

`dragThreshold` 约 10–15px，区分点击与拖动。

## 合成

- 仅 `definitionId` 相同可合
- 满级（如 `coffee_08`）不可继续合成
- 合成后新 `uid`
- 动画不得控制核心状态：先逻辑后事件后动画

## 生成器

| id | 解锁 | 产出 |
| --- | --- | --- |
| coffee_machine | Lv1 | coffee_01 85% / coffee_02 15% |
| flower_basket | Lv1 | flower_01 85% / flower_02 15% |
| dessert_oven | Lv3 | dessert_01 85% / dessert_02 15% |
| gift_box | Lv5 | gift_01 85% / gift_02 15% |

空格选择：从左到右、从上到下第一个空格。  
棋盘满不扣体力。

## 体力

- max 50 / initial 50 / cost 1
- 每 120s +1，离线用 `lastEnergyAt` 计算

## 订单

- 同时 3 个
- 1–2 种需求
- 目标等级优先 Lv2–Lv5
- 交付时重新校验库存，从 index 最小的匹配物扣除
- 首单固定教程单：`coffee_02 × 1` → 20 coins / 10 xp / 1 heart

## 等级

| Lv | XP |
| --- | --- |
| 1 | 0 |
| 2 | 30 |
| 3 | 80 |
| 4 | 150 |
| 5 | 250 |

Lv3 解锁 dessert；Lv5 解锁 gift。

## 存档

- key：`our-love-story-save`
- `version: 1`
- 自动保存（可 debounce 100–300ms）
- 坏档：备份/忽略 → 默认档 → 正常启动

## UI 布局（750×1334）

状态栏 → 订单区（3）→ 7×9 棋盘 → 生成器 Dock。
