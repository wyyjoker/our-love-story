# 订单交付与奖励反馈精修（2026-11-16）

本轮接续 [五级补给与玩法精修](NOV16_REFINEMENT.md)，仍为 1.3.0 本地候选，存档维持 v7，未上传。订单数量、奖励、体力、产出和故事配置没有在本轮调整。

> 本页记录交付反馈阶段的历史构建。后续已取消换单、替换顾客与导航插画，并加入 v8 实体剪刀；当前行为和验证以 [人物订单与工具精修](CUSTOMER_TOOLS.md) 为准。

## 实际交互

1. 订单卡使用奶油纸色、轻描边与柔和珊瑚粉交付按钮；备齐后有绿色细框和完成勾。三个订单槽位置固定，换单收进右下角的小入口，展开后可免费刷新、钻石换单或关闭。
2. 点击交付后，所需物品从原棋盘格飞向顾客，头像轻弹，出现爱心致谢及独立铃声。仅锁住正在交付的订单，其他订单与棋盘仍可操作。
3. 金币、经验和爱心分别飞向对应资源位置，到账时数值轻弹；原订单随后在同一位置柔和换新。取消大段“交付成功”提示。完整反馈约一秒，不弹强制确认框。
4. 交付导致的升级在物品和奖励反馈结束后展示；领取升级礼包后使用相同的资源飞行动效，再展示下一份待领礼包。连续升级不会把数个弹窗叠在一起。
5. 开箱、升级页和首次发现统一为奶油纸色、珊瑚粉、柔金色的轻量反馈。首次发现使用带物品插画的小卡片；普通合成不再反复弹“合成成功”，保留物品动效和声音。

## 数据与生命周期

- 交易仍由原有 `GameContext` / 玩法服务即时提交并保存，动画不扣物品、不抽奖、不发放资源。状态栏的短暂延迟只是显示层持有的差额，不改变可保存的资产。
- 每次交付捕获原订单 UID、所需物品图标和原格坐标；卡片冻结旧内容至反馈结束，避免新订单出现在旧物品动画下面。同一订单连点不能再次交付，不同槽位可以连续操作。
- 奖励展示按交付 UID 独立记录，支持不同奖励先后到账。经验区等本轮经验飞入后再显示实际等级；所有展示差额均可在离开页面时清空。
- 切页清除画面反馈、释放卡片并恢复实际资源数值。动画中重启直接恢复已经保存的实际进度，不重播、不补发奖励。销毁时停止对应节点的动画。
- 本轮复用现有插画与声音，没有引入新的图片依赖；新增模块的导入元数据由 Creator 实际生成。
