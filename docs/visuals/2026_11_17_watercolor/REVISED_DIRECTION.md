# 合成页修订方向

以用户后续提供的 `mmexport1794930478969.jpg` 为布局参考，以最初两张小屋效果图为画风参考。

- 棋盘改为 **7列×9行，共63格**，替代早先6×7方案。
- 生成器在主棋盘格内生产和合成，同种同级可拖动合成，任务可获得副本。每台可拖入普通背包占一格，取回后使用；独立生成器储存区的旧稿仍归档。领取时没有棋盘空格则保留奖励未领取，先提示腾位置。
- 保留奶油白、浅木和细腻水彩；棋盘不采用蓝色。备齐物品的格子用浅豆绿底和清晰大绿勾。
- 三个顾客以大半身人物为主体，站在需求托盘后面，需求物品放托盘，奖励在人物旁，交付按钮居中突出。
- 左上角头像、等级和经验进度；体力、金币和钻石在顶部横排，商店位于右上方，避开系统胶囊。
- 底部左侧背包、中间物品详情、右侧回家园；任务与回忆由家园入口进入。
- 新画风和数值仍是视觉方案，尚未修改游戏规则；具体安全区和短屏适配在落地时验证。

此前生成的合成页与生成器抽屉图已被替代并移入归档，不在当前方案册展示。现已按修订后的合成页补齐29张主要页面与状态效果图，包含独立商店方案。
