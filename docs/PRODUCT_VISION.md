# 产品愿景

> 做一个送给重要的人的专属 Merge 情侣小游戏。

核心不是商业化。核心体验是：

```text
玩游戏
↓
升级
↓
解锁回忆
↓
看到共同经历
↓
继续玩
↓
发现隐藏彩蛋
```

## 产品原则

她开始只是觉得：“这是一个合成小游戏。”

继续玩：“怎么这里有我们的东西？”

继续升级：“这个不是我们去过的地方吗？”

继续：“这张照片怎么也在里面？”

再继续：解锁共同回忆、旅行、纪念日、照片、隐藏彩蛋。

最后发现：整个游戏其实都是两个人的故事。

## V0.1 的角色

V0.1 只做技术地基：稳定可玩的 Merge 核心循环。  
后续的回忆 / 照片 / 旅行 / 剧情 / 彩蛋 / 装修必须建立在现在的架构上，而不是推倒重来。

## 语气与情感

- 温柔、浪漫、轻松、干净、不幼稚
- 不是商业数值逼氪，前十分钟要爽、容易理解、能感受到成长
